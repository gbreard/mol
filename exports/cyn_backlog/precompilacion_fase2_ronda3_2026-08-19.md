## R350_operario_deposito_logistica — vol 164 · destino actual 9333.8

**Código correcto (Cyn):** 9333.8 / 9333.3 según tareas

> «No asignar un único destino automático a “operario/a de depósito”, “picker” u otros títulos logísticos. Mantener 9333.8 cuando predominan recepción, control, preparación, embalaje, almacenamiento y expedición de mercadería; usar 9333.3 cuando predominan carga, descarga, traslado, apilado y manipulación física de mercancías dentro del almacén. Resolver los casos de picking/armado de pedidos según las tareas predominantes.»

## R95_tech_lead_ia_ml — vol 174 · destino actual 2512.4

**Código correcto (Cyn):** 2511.11 para la rama AI Engineer / IA Engineer / Machine Learning Engineer / ML Engineer cuando las tareas sean efectivamente de ingeniería de IA/ML.

> «Corregir R95. No agrupar automáticamente Tech Lead, Arquitecto IA, ML Engineer, AI Engineer y Lead Developer bajo 2512.4 desarrollador de software/desarrolladora de software. La rama Ingeniero/a de IA / AI Engineer / Machine Learning Engineer / ML Engineer queda validada en 2511.11 “ingeniero de inteligencia artificial/ingeniera de inteligencia artificial” cuando el núcleo es diseñar, desarrollar, integrar, entrenar, evaluar o implementar soluciones y modelos de IA/ML. Tech Lead, Lead Developer y Arquitecto IA no deben recibir un código único por título: deben resolverse según las tareas efectivas de desarrollo, arquitectura, liderazgo técnico o IA.»

## R306_mantenimiento_electrico — vol 92 · destino actual 7412.3
